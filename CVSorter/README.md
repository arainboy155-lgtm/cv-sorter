# CV Sorter – Teacher CV Auto Sorting App

Windows desktop app jo teacher CVs (PDF / DOCX / TXT) parh kar khud detect karti hai ke CV kis subject ki hai
(English, Math, Physics, Chemistry, Biology, Computer, Urdu, Islamiat, waghera) aur alag folders mein save kar deti hai.

## Download (.exe)
**Actions** tab → latest "Build Windows EXE" run → neeche **Artifacts** se `CV-Sorter-Windows` download karein.
Ya **Releases** section se latest version.

## Features
- Subject auto-detect + alag folders
- Naam, email, phone, experience extract
- Duplicate detection, Manual Review folder
- Right-click se subject change, search, Excel report
- Auto-Watch folder, drag & drop

## Source se chalana
```
pip install -r requirements.txt
python cv_sorter_app.py
```
